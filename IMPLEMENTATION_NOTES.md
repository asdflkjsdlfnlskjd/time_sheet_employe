# Реализация Импорта/Экспорта Табеля в Excel

## ✅ Что было реализовано

### 1. **Создание Export класса** (`app/Exports/TimeRecordExport.php`)

Класс отвечает за экспорт данных табеля:
- Генерирует CSV данные в правильном формате
- Поддерживает фильтрацию по отделам
- Включает статистику (рабочие дни, часы)
- Экспортирует с правильной кодировкой UTF-8 и BOM
- Форматирует вывод: статус + часы (например: "ОТ(8.5ч)")

**Основные методы:**
- `generateCsv()` - генерирует массив данных
- `toCsv()` - экспортирует в CSV формат
- `toXlsx()` - экспортирует (через CSV)

### 2. **Создание Import класса** (`app/Imports/TimeRecordImport.php`)

Класс отвечает за импорт данных:
- Парсит CSV/XLSX файлы
- Распознает различные форматы времени/статусов
- Проверяет права доступа (для обычных админов)
- Валидирует данные перед сохранением
- Сообщает об ошибках при импорте
- Поддерживает несколько форматов ячеек:
  - "ОТ(8.5ч)" - статус с часами
  - "8.5" - просто часы
  - "—" - присутствовал
  - "-" - нет данных

**Основные методы:**
- `import()` - запускает процесс импорта
- `parseTimeData()` - парсит значение ячейки
- `findStatusByShort()` - находит статус по коду
- `saveRecords()` - сохраняет в БД

### 3. **Обновление Controller** (`app/Http/Controllers/Main/MainController.php`)

Методы контроллера переработаны для использования новых классов:

**exportExcel()**
- Получает параметры (месяц, год, отдел)
- Проверяет авторизацию и права доступа
- Использует Export класс для генерации данных
- Возвращает CSV файл

**importExcel()**
- Валидирует входные параметры
- Загружает файл временно
- Использует Import класс для обработки
- Возвращает результат с количеством загруженных/пропущенных записей
- Очищает временные файлы

```

```

month=4

## 🚀 Рекомендуемый Рабочий Процесс

1. **Работа в системе**: Внесите данные табеля
2. **Экспорт**: Сохраните табель в файл (для резервной копии)
3. **Редактирование**: Откройте в Excel, внесите корректировки
4. **Импорт**: Загрузите отредактированный файл обратно
5. **Проверка**: Убедитесь, что все данные загружены правильно

## 🔄 Последовательность Операций при Импорте

```
1. Валидация параметров (месяц, год, файл)
2. Загрузка файла во временное хранилище
3. Открытие файла и чтение CSV
4. Пропуск строк заголовка (первые 4 строки)
5. Для каждой строки:
   - Поиск сотрудника по табельному номеру
   - Проверка прав доступа
   - Парсинг 31 дня
   - Распознавание статусов и часов
6. Сохранение в базу (updateOrCreate)
7. Удаление временного файла
8. Возврат результата
```

## 📊 Формат Экспортируемого Файла

```
Row 1: Табель учета рабочего времени,Апрель,2026
Row 2: (пусто)
Row 3: Сотрудник,Табельный номер,Отдел,День 1,День 2,...,День 30,Рабочих дней,Всего часов
Row 4+: [Данные сотрудников]

Пример ячейки дня: "ОТ(8ч)" или "—" или "-"
```

## 🐛 Известные Ограничения

- Максимальный размер файла зависит от настроек PHP
- Поддерживаются месяцы с 28-31 днями
- Обычные админы не могут импортировать чужие отделы
- При импорте все данные за месяц перезаписываются
