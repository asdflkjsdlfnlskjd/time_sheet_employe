## 🚀 Как Использовать

### Экспорт:
1. Перейти на страницу "Табель"
2. Нажать кнопку **"📥 Экспорт"**
3. Файл загрузится автоматически

### Импорт:
1. Перейти на страницу "Табель"
2. Нажать кнопку **"📨 Импорт"**
3. Выбрать месяц, год и файл
4. Нажать **"Импортировать"**

## 📊 Примеры Форматов

### Экспортируемый CSV:
```
Табель учета рабочего времени,Апрель,2026

Сотрудник,Табельный номер,Отдел,День 1,День 2,...,День 30,Рабочих дней,Всего часов
Иванов Иван Иванович,001,Отдел разработки,—,—,...,—,22,176
```

### Поддерживаемые форматы ячеек при импорте:
- `ОТ(8ч)` - статус "Отсутствовал" с 8 часами
- `8.5` - просто часы (интерпретируется как присутствие)
- `—` - присутствовал
- `-` - нет данных

## ⚙️ Маршруты

## 🐛 Возможные Проблемы и Решения

| Проблема | Решение |
|----------|---------|
| Файл не загружается | Проверить формат (CSV/XLSX), размер < limit |
| Ошибка "Табельный номер не найден" | Убедиться, что номер существует в системе |
| "Нет доступа" | Для обычного админа - используется его отдел |
| Данные не импортированы | Проверить логи, запустить заново |
