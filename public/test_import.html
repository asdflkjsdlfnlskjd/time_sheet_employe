2. Статусы в табеле

Используйте следующие статусы при импорте:

Короткий код Описание Пример
— Присутствовал (Обычный день) —(8.5ч)
ОТ Отсутствовал ОТ(0ч)
ОП Опоздал ОП(7ч)
РУ Ранний уход РУ(6ч)
ОТП Отпуск ОТП(0ч)
БО Больничный БО(0ч)
ВЫХ Выходной ВЫХ(0ч)

3. Инструкции по импорту

Шаг 1: Скачайте шаблон импорта выше

Шаг 2: Откройте файл в Excel и отредактируйте данные

Шаг 3: Сохраните файл как CSV или XLSX

Шаг 4: Зайдите в систему и нажмите "Импорт" в главном меню

Шаг 5: Выберите месяц, год и загрузите файл

ℹ️ Внимание: Существующие данные за выбранный месяц будут перезаписаны!

4. Формат файла

Файл имеет следующую структуру:

Строка 1: Заголовок (Табель учета рабочего времени)
Строка 2: Месяц и год
Строка 3: Пустая
Строка 4: Легенда статусов
Строка 5: Заголовки таблицы
Строка 6+: Данные сотрудников

Столбцы:
A - Фамилия
B - Имя
C - Отчество
D - Табельный номер
E - Отдел ID
F-AK - Дни месяца (1-30/31)

5. Проверка входа

Если возникли проблемы с входом:

  • Убедитесь, что вы используете правильное имя пользователя и пароль
  • Проверьте, что сессия не истекла
  • Очистите кэш браузера (Ctrl+Shift+Delete)
  • Попробуйте другой браузер

Адрес входа: /login
