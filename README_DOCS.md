## 🔍 Быстрый Справочник

### API Endpoints

| Метод | URL | Описание |
|-------|-----|---------|
| POST | /main/save-time-records | Массовое сохранение записей |
| PATCH | /time-records/{id}/{date} | Единичное обновление записи |

### HTTP Статусы

| Код | Значение | Когда |
|-----|----------|-------|
| 200 | ✅ OK | Успешно |
| 401 | ❌ Unauthorized | Не авторизован |
| 403 | ❌ Forbidden | Нет прав доступа |
| 422 | ❌ Unprocessable | Ошибка валидации |
| 500 | ❌ Internal Server Error | Ошибка сервера |

### Допустимые Статусы

- `present` - Присутствует (—)
- `absent` - Отсутствовал (ОТ)
- `late` - Опоздал (ОП)
- `early_leave` - Ранний уход (РУ)
- `vacation` - Отпуск (ОТП)
- `sick_leave` - Больничный (БО)
- `day_off` - Выходной (ВЫХ)
